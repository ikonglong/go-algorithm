
## 回溯代码模板

多阶段决策模型

```
result = [] // 最终结果列表

def backtrack(决策阶段k, 此阶段选择列表, 已决策阶段所做的选择构成的路径)
  if 满足结束条件（所有的阶段决策都已完成或已得到可行解）
    // 如果循环内部已确保解是可行的，就不需要此检查
    if 路径为可行解
      result.add(路径)
    return

  for 选择 in [此阶段选择列表]:
    // 做出选择（即完成决策），更改「调用节点」状态
    // 递归调用形成了一棵递归树。每一次递归调用，就自动创建了一个调用节点
    路径.add(选择)
    // 更改选择列表后，即为k+1阶段对应的选择列表了
    // 也可以不更改选择列表，在每次循环开始时动态过滤出当前阶段对应的选择列表
    选择列表.remove(选择)
    backtrack(决策阶段k+1, 选择列表, 路径)
    // 在归的过程中，可回溯到任意一个阶段，因此需要
    // 撤销前面做出的选择，恢复「调用节点」状态，以尝试其他选择
    路径.remove(选择)
    选择列表.add(选择)
```
